## Featured Projects

### [Lume](https://github.com/ledrodh/Lume)

Document Restoration & E-book Processing

A document-processing platform designed to transform complex scanned PDFs into structured and navigable e-books.

Combines OCR, document diagnostics, layout analysis, PDF processing, and a custom HTML restoration engine to preserve document structure, reconstruct footnotes, and generate validated EPUBs.

Technologies: Python, Marker, Surya, PyMuPDF, Pandoc, HTML Processing, EPUB 3.

### [StockFlow API](https://github.com/ledrodh/stockflow-api)

Transactional Inventory & Order Management

A backend system designed around data integrity and reliable transaction processing. Implements database-backed idempotency, pessimistic concurrency control, an immutable inventory ledger, and snapshot-consistent reconciliation.

Technologies: Python, FastAPI, SQLAlchemy, PostgreSQL, Alembic, Pytest, Docker, React, TypeScript.

### [EchoScope AI](https://github.com/ledrodh/EchoScope-AI)

YouTube Competitive Intelligence & Strategic Analytics

A data analytics platform that collects and compares YouTube channel performance, tracks historical snapshots, and generates evidence-based strategic reports using Google Gemini.

Built around the principle "Python Calculates; Gemini Interprets", separating deterministic statistical calculations from AI-generated interpretations.

- Historical snapshot isolation and channel comparisons.
- Deterministic metrics and growth analysis.
- Resilient data collection and partial-failure handling.
- Streamlit dashboard and independent CLI.
- Structured AI reports with Pydantic validation.

Technologies: Python, YouTube Data API v3, SQLite, Streamlit, Google Gemini, Pydantic, Pytest.

### [GeoBrief Automated](https://github.com/ledrodh/GeoBrief-Automated)

OSINT & Intelligence Automation

An automated information-gathering pipeline that aggregates news and Telegram data, filters relevant information using Google Gemini, and delivers synthesized geopolitical briefings through Telegram.

Technologies: Python, Playwright, Telethon, SQLite, Google Gemini, Telegram Bot API.

### [OmniFetch](https://github.com/ledrodh/OmniFetch)

Local-First Media Inspection & Processing

A local-first media utility designed to inspect, select, download, trim, and process public media streams supported by `yt-dlp`.

Combines original-language audio prioritization, FFmpeg-based remuxing and trimming, sequential batch processing, and isolated resource management with layered IPv4/IPv6 anti-SSRF protections.

Technologies: Python, Streamlit, yt-dlp, FFmpeg, FFprobe, Pytest, Ruff, Pyright, Docker.
